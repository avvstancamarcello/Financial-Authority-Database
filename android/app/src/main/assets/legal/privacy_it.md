# Privacy

Questa app funziona principalmente offline e carica dataset locali inclusi nell'APK.

- Non richiede account utente.
- Non gestisce pagamenti o transazioni.
- Non invia automaticamente i dati di ricerca o preferiti a server remoti.
- I link esterni vengono aperti nel browser del dispositivo su scelta esplicita dell'utente.

Per i dettagli legali completi fare riferimento anche alla versione web del progetto (`privacy.html`).
