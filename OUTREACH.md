## 🗓️ Strategia di diffusione in fasi

| Fase | Obiettivo | Azioni | Tempistica |
|---|---|---|---|
| 1. Notifica alle piattaforme AI | Rendere nota la risorsa ai sistemi di discovery | Inviare feedback, submit URL, condividere repo + landing page + JSON | Giorni 1-3 |
| 2. Submission a directory di dataset | Rafforzare la reperibilità come dataset | Curare markup `Dataset`, citare JSON, usare sitemap e pagine dataset-friendly | Giorni 3-7 |
| 3. Media e press release | Generare citazioni secondarie e backlink | Preparare email breve, descrizione standard, quote e asset pubblici | Settimana 2 |
| 4. Academic / institutional outreach | Favorire uso come fonte e riferimento | Contattare ricercatori, associazioni consumatori, enti e osservatori | Settimane 2-4 |

### Fase 1: Notifica alle piattaforme AI

- [ ] Google: inviare feedback contestuale in AI Overviews / Search
- [ ] OpenAI: segnalare la risorsa in contesti research/public-interest
- [ ] Bing: verificare sito, inviare sitemap, usare URL submission
- [ ] Anthropic: condividere dataset come risorsa per grounding e safety
- [ ] Perplexity: usare help/community/email per segnalare la fonte
- [ ] Gemini: inviare feedback in-product con URL della risorsa

### Fase 2: Submission a directory di dataset

- [ ] Verificare presenza del markup `Dataset`
- [ ] Tenere la landing page in sitemap
- [ ] Usare descrizioni coerenti tra sito, repo e documentazione
- [ ] Privilegiare URL stabili e pubblici

### Fase 3: Media e press release

- [ ] Preparare un comunicato di 5-7 righe
- [ ] Inviare a media su consumer protection, fintech, cybersecurity
- [ ] Inserire un link diretto alla sezione `#countries-section`
- [ ] Allegare 1 screenshot e il repository GitHub

### Fase 4: Academic / institutional outreach

- [ ] Contattare università, centri ricerca, osservatori antifrode
- [ ] Coinvolgere associazioni consumatori e operatori di compliance
- [ ] Evidenziare il valore pratico per due diligence e tutela utenti
